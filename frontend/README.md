# SocialFeed - Frontend

This is the React frontend for the SocialFeed application, built with Vite. 

For full documentation, architecture details, and setup instructions for the entire MERN stack, please refer to the **main `README.md` located in the root directory** of the project (`../README.md`).

## Scripts

- `npm install` - Install dependencies
- `npm run dev` - Start development server
- `npm run build` - Build for production
